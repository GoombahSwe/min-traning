Min Träning v6

PWA med egna träningsprogram. Öppna via HTTPS för installation på Android.

Nytt: skapa, öppna, uppdatera och radera egna program med valfria övningar, set, kg och repetitioner. Träningshistorik, viktlogg, schema och JSON-säkerhetskopia finns kvar.

Data lagras lokalt i webbläsaren. Gör regelbundna säkerhetskopior.
